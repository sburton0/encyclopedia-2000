# Security Policy

## Supported versions

Only the newest release of Encyclopedia 2000 gets security fixes. The installed version updates itself automatically; if you use the portable version, download the latest one from the [Releases page](https://github.com/sburton0/encyclopedia-2000/releases/latest).

## Reporting a vulnerability

If you find a security problem, please **report it privately** instead of opening a public issue or posting it on Discord, so it can be fixed before anyone can take advantage of it.

Use GitHub's private reporting: go to the [Security tab](https://github.com/sburton0/encyclopedia-2000/security) and click **Report a vulnerability**. Please include:

- What the problem is and what someone could do with it
- Steps to reproduce it
- The app version (Help → Send Feedback shows it) and your Windows version

You'll get a reply as soon as possible, usually within a few days. Encyclopedia 2000 is maintained by one person, so please allow some time for a fix. You'll be credited in the release notes if you'd like.

## Official downloads

Encyclopedia 2000 is only distributed through its [GitHub Releases page](https://github.com/sburton0/encyclopedia-2000/releases) and [encyclopedia2000.com](https://encyclopedia2000.com). Official builds from version 0.1.1 onward are signed by **Scott Burton** (right-click the file → Properties → Digital Signatures). If you find a copy elsewhere, especially one that isn't signed, please don't run it, and let us know.
